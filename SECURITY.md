# Security Policy

## Reporting a Vulnerability

We take the security of `lakehouse-lite-engine` seriously. If you discover a security vulnerability, please report it privately rather than opening a public issue.

### Security Contacts

* **Primary:** `rajputmuhammadali979@gmail.com`
* **Secondary:** `rjptmhmmd@gmail.com`

### Security SLA

We aim to acknowledge receipt of all vulnerability reports within **48 hours** and provide a resolution plan within 7 business days.

## Supported Versions

| Version | Supported | Python Version | Dependency Bounds |
|---|---|---|---|
| `0.1.x` | :white_check_mark: | `>=3.13,<3.14` | Pydantic `>=2.10`, PyArrow `>=18.0`, PyIceberg `>=0.11`, Polars `>=1.21`, DuckDB `>=1.1` |
